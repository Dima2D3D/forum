# GREFFRLEND Forum v2

Это чистая рабочая основа форума на PHP + JSON без MySQL.

Тестировать: `/v2/index.php`

Поддерживает: регистрацию, вход, посты, категории, лайки, комментарии и ответы, подписки, уведомления, профили, поиск, жалобы и owner-панель. Данные хранятся в `v2/data/`, загрузки — в `v2/uploads/`.

Владелец определяется по `admins@greffrlend.fun`.

Важно: перед продакшеном настройте PHP `mail()`/SMTP для почты и HTTPS. Эта v2-основа создаётся отдельно от старых файлов, чтобы не ломать текущий проект во время миграции.
